# cubic-fields-explicit-units

PARI/GP scripts accompanying

> I. Kimura and H. Umemoto,
> *On an infinite family of cubic fields with explicit fundamental units*.

For an integer `b != 0, 1` let `K_b = Q(theta)` be the cubic field generated by the
unique real root of

```
f_b(x) = x^3 - 3 b x - b^3,     disc(f_b) = -27 b^3 (b^3 - 4).
```

`K_b` is a cubic field which is not totally real, so its unit group has free part of
rank one. The paper studies the unit

```
eta_b = -1 / (theta - (b+1)) = ((b+1) - theta)^(-1) > 1,
```

proves that it is the fundamental unit of `K_b` for a positive density of `b`,
determines the `b` for which it is a square (they are parametrized by the Pell
equation `D^2 - 3E^2 = 1`, hence infinite in number), computes the index
`[O_{K_b} : Z[theta]]` and an integral basis prime by prime, and constructs
infinitely many biquadratic fields whose 3-class field tower has length greater
than 1.

These scripts are the computations behind the numerical statements in the paper.
**They verify; they do not prove.** Every theorem in the paper has a proof there
that is independent of anything computed here. What the scripts do is confirm the
statements on finite ranges, which is how they were found and how they were checked
before being asserted.

## Requirements

PARI/GP. The runs reported in the paper were made with **PARI/GP 2.17.4**; any
recent 2.x should work. No other dependencies.

```
gp -q --default parisize=2G <script>.gp
```

Each script prints its own results and reports its failure count (several end
with an explicit `GATE: GREEN` line); every script in this repository
terminates with **0 failures**. Some allocate a larger stack and print a PARI
warning saying so, which is expected. The longer runs (`check-paper-audit.gp`,
`check-star.gp`, `check-p3-3rank.gp`, `scan-cube.gp`) take a few minutes.

To run everything:

```
for s in *.gp; do echo "=== $s ==="; gp -q --default parisize=2G "$s"; done
```

## What each script checks

Section and theorem numbers refer to the arXiv version of the paper (Remark 5.7,
the conditional bound under Baker's explicit *abc* conjecture, is new there; the
numbers of §5 from 5.7 on are one higher than in earlier versions).

### Setup, integral basis and the index (§§2–3)

| script | checks |
| --- | --- |
| `verify-setup.gp` | `disc(f_b)`, `D_K`, the index, the minimal polynomials of `eps_b` and `eta_b`, and the sizes of the real embeddings (Prop. 2.1, Lemma 2.2) |
| `check-basis-direct.gp` | `omega = (theta^2-3b)/b` has minimal polynomial `X^3+3X^2-b^3` (symbolically in `b`, and for `|b| <= 400`); the lattice discriminant `-27b(b^3-4)`; maximality in all 227 cases of the squarefree regime; `zeta = omega+1` satisfies `z^3-3z = b^3-2`, identifying the sister family (Lemma 3.7, Rem. 3.8, Cor. 3.9) |
| `check-ram.gp` | the closed forms for `v_p(a)` and `v_p(D_K)` against `nfdisc`, 1198 cases, and the quadratic-factor certificates at `p = 2, 3` (Thms. 3.3, 3.5) |
| `check-LN.gp` | the same decomposition data computed independently from Llorente–Nart, Theorem 2 — an outside cross-check of §3, 598 cases |

### The fundamental unit (§4)

| script | checks |
| --- | --- |
| `verify-artin.gp` | Artin's inequality `|D(e)| <= 4e^3 + 24` (Lemma 4.1) against the true fundamental unit, and the size inequalities of Lemma 4.3 with their polynomial certificates |
| `check-negative.gp` | the negative parameters: the exception scan, the Pell description, and the main theorem for all 626 admissible `b` in `[-2000,-2]` (Thm. 4.4) |
| `check-p2-nofixsq.gp` | Lemma 4.5 (no fixed square divisor of `x^3 -+ 4`, feeding Thm. 4.6 and Cor. 4.7): checked for all primes `q < 200`, with the root count "at most three" used for `q >= 5` |
| `check-prime-stats.gp` | the numerical remark after Cor. 4.7: of the 2260 primes `5 <= p < 20000`, exactly 2102 have `p^3-4` squarefree and 2094 have `p^3+4` squarefree (93.0% / 92.7%), and the heuristic density `prod_q (1 - rho(q)/(q^2-q)) = 0.926485...` (Rem. 4.8) |

### The exceptional set, cubes included (§5)

| script | checks |
| --- | --- |
| `verify-pell.gp` | the Pell prediction of the square-exceptions, confirmed against `bnfisunit` (Thm. 5.1) |
| `verify-pellclosed.gp` | the closed form `b_pm(k) = (f_{2k-1}-1)/2 +- 2 f_{k-1}` and the Binet identities behind it (Thm. 5.2) |
| `check-neg-pell.gp` | the four-branch enumeration, exhibiting the two branches that give negative `b` |
| `scan-cube.gp` | the exponent `n` with `eta_b = eta_0^n` for all `|b| <= 600`, both signs: `eta_b` is a cube exactly when `b = 9` (Lemma 5.3) |
| `check-cube-thue.gp` | the reduction of the cube system to the Thue equation `g^3-9dg^2+18d^2g-9d^3 = ±1`, and its solution, giving `b` in `{0, 9}` (Lemma 5.3) |
| `check-star.gp` | condition `(star)` over `|b| <= 3000`: it fails exactly at `b = -75, -3, 3, 9`, with unit exponents 4, 8, 13, 6; all 16 Pell exceptions against `(star)`; `v_2(b^3-4) <= 2` and `v_3(b^3-4) <= 1` (Thm. 5.5, Rem. 5.6) |
| `check-baker-abc.gp` | Rem. 5.7, for `3` not dividing `b`: the four coprime triples (`4+(b^3-4)=b^3` and its variants), their radicals, `z >= |b|^3/4` and `N <= 2Rk·ts`, for all 13331 values with `3 <= |b| <= 10^4`; `(star)` itself on that range, already from `|D_K| >= 27Rt` (eq. (5.6)); the constants `0.29`, `1.08` and `log(24/5)+(15/13)log 1.08 <= 2`; and the threshold `W = 200699842747` (so `L < 5.662e12` and `log|b| < 2.18e12`), certified in exact rational arithmetic with explicit exponential-series bounds for the logarithms. Also reproduces the table of Laishram–Shorey's Theorem 1, as a check of the reading of Robin's bound, and asserts the three discrepancies found there. Runs in a few seconds |
| `check-p1-regulator.gp` | the regulator statement at a square-exception, `R = log eta_0 <= (1/2) log eta_b ~ log(sqrt(3)|b|)`; the exponents `eta_b = eta_0^n` for `b = -75, -3, 9` quoted in Rem. 5.6; and the sign/parity claim of Thm. 5.2 |
| `check-louboutin.gp` | Rem. 5.9: the family meets neither the parametrized nor the sporadic exceptions of Louboutin's theorem on orders generated by a unit, so `eta_b` is the fundamental unit of `Z[eta_b]` for every `b` (identity `Q^2-4P = -3(b-1)^2` symbolically, disc bound, and a direct sweep) |
| `check-negexc.gp` | the twelve exact identities of Lemma 5.13 (`b = uw`, `m = |uz|`, `u+w = 2c`, …); the main lemma `v_p(z) <= v_p(3c)` over 118 branches; the size bound (Lemma 5.15); the six small cases; `b = -3` as the sole exception (Lemmas 5.12–5.15, Thm. 5.16) |
| `check-p4-identities.gp` | every identity whose routine expansion the paper compresses: (I),(II) and the quartic in Thm. 5.1, the `u,w,z,c` identities of Lemma 5.13, and the decomposition `z = z_1 + z_2` of Lemma 5.15 — all in exact integer arithmetic over the Pell parametrization |

## Scope

These are the scripts for the results in the paper. The computations for the
exponents `q >= 5` — the genus computations and the appeal to Faltings' theorem
mentioned in Remark 5.8 — belong to a sequel and are not included here.
