# cubic-fields-explicit-units

PARI/GP scripts accompanying

> I. Kimura and H. Umemoto,
> *On an infinite family of cubic fields with explicit fundamental units*.

For an integer `b != 0, 1` let `K_b = Q(theta)` be the cubic field generated by the
unique real root of

```
f_b(x) = x^3 - 3 b x - b^3,     disc(f_b) = -27 b^3 (b^3 - 4).
```

`K_b` is a cubic field which is not totally real, so its unit group has free part of
rank one. The paper studies the unit

```
eta_b = -1 / (theta - (b+1)) = ((b+1) - theta)^(-1) > 1,
```

proves that it is the fundamental unit of `K_b` for a positive density of `b`,
determines the `b` for which it is a square (they are parametrized by the Pell
equation `D^2 - 3E^2 = 1`, hence infinite in number), computes the index
`[O_{K_b} : Z[theta]]` and an integral basis prime by prime, and constructs
infinitely many biquadratic fields whose 3-class field tower has length greater
than 1.

These scripts are the computations behind the numerical statements in the paper.
**They verify; they do not prove.** Every theorem in the paper has a proof there
that is independent of anything computed here. What the scripts do is confirm the
statements on finite ranges, which is how they were found and how they were checked
before being asserted.

## Requirements

PARI/GP 2.x. No other dependencies.

```
gp -q --default parisize=2G <script>.gp
```

Each script prints its own results and reports its failure count; every script in
this repository terminates with **0 failures**. Some allocate a larger stack and
print a PARI warning saying so, which is expected. The longer runs
(`check-paper-audit.gp`, `check-star.gp`, `scan-cube.gp`) take a few minutes.

To run everything:

```
for s in *.gp; do echo "=== $s ==="; gp -q --default parisize=2G "$s"; done
```

## What each script checks

Section and theorem numbers refer to the paper.

### Setup, integral basis and the index (§§2–3)

| script | checks |
| --- | --- |
| `verify-setup.gp` | `disc(f_b)`, `D_K`, the index, the minimal polynomials of `eps_b` and `eta_b`, and the sizes of the real embeddings (Prop. 2.1, Lemma 2.2) |
| `check-basis-direct.gp` | `omega = (theta^2-3b)/b` has minimal polynomial `X^3+3X^2-b^3` (symbolically in `b`, and for `|b| <= 400`); the lattice discriminant `-27b(b^3-4)`; maximality in all 227 cases of the squarefree regime; `zeta = omega+1` satisfies `z^3-3z = b^3-2`, identifying the sister family (Lemma 3.7, Rem. 3.8, Cor. 3.9) |
| `check-ram.gp` | the closed forms for `v_p(a)` and `v_p(D_K)` against `nfdisc`, 1198 cases, and the quadratic-factor certificates at `p = 2, 3` (Thms. 3.3, 3.5) |
| `check-LN.gp` | the same decomposition data computed independently from Llorente–Nart, Theorem 2 — an outside cross-check of §3, 598 cases |

### The fundamental unit (§4)

| script | checks |
| --- | --- |
| `verify-artin.gp` | Artin's inequality `|D(e)| <= 4e^3 + 24` against the true fundamental unit, and the size inequalities of Lemma 4.4 with their polynomial certificates |
| `check-negative.gp` | the negative parameters: the exception scan, the Pell description, and the main theorem for all 626 admissible `b` in `[-2000,-2]` (Thm. 4.6) |

### The exceptional set (§5)

| script | checks |
| --- | --- |
| `verify-pell.gp` | the Pell prediction of the square-exceptions, confirmed against `bnfisunit` (Thm. 5.1) |
| `verify-pellclosed.gp` | the closed form `b_pm(k) = (f_{2k-1}-1)/2 +- 2 f_{k-1}` and the Binet identities behind it (Thm. 5.2) |
| `check-neg-pell.gp` | the four-branch enumeration, exhibiting the two branches that give negative `b` |
| `check-star.gp` | condition `(star)` over `|b| <= 3000`: it fails exactly at `b = -75, -3, 3, 9`, with unit exponents 4, 8, 13, 6; all 16 Pell exceptions against `(star)`; `v_2(b^3-4) <= 2` and `v_3(b^3-4) <= 1` (Thm. 5.3, Rem. 5.4) |
| `check-negexc.gp` | the twelve exact identities of Lemma 5.9 (`b = uw`, `m = |uv|`, `u+w = 2c`, …); the main lemma `v_p(v) <= v_p(3c)` over 118 branches; the size bound; the six small cases; `b = -3` as the sole exception (Lemmas 5.9–5.11, Thm. 5.12) |

### Cubes and the biquadratic fields (§6)

| script | checks |
| --- | --- |
| `scan-cube.gp` | the exponent `n` with `eta_b = eta_0^n` for all `|b| <= 600`, both signs: `eta_b` is a cube exactly when `b = 9` (Lemma 6.4) |
| `check-cube-thue.gp` | the reduction of the cube system to the Thue equation `g^3-9dg^2+18d^2g-9d^3 = ±1`, and its solution, giving `b` in `{0, 9}` (Lemma 6.4) |
| `check-biquad.gp` | the 3-class field tower construction: the congruence condition against `v_3(b) >= 2`, the factorization `3 = p_1 p_2^2`, the absence of a totally ramified prime, `eta_b = 1 mod p_1^2 p_2^3`, and the 3-rank of `Cl(F_b)` (Prop. 6.3, Thm. 6.5) |

### Audits of the manuscript

| script | checks |
| --- | --- |
| `check-m-fixes.gp` | every statement written into the draft at one revision, re-checked one by one |
| `check-paper-audit.gp` | the pre-submission audit: the exception scan to `|b| <= 3000`, the size inequalities, the 2- and 3-adic decomposition types, the four-branch symbolic certificates, the 3-rank of `Cl(F_b)` |
| `check-audit-post-trim.gp` | that the index criterion (Thm. 5.6) is an *equivalence*, on 35238 pairs `(b,p)` with `|b| <= 400`, `p < 200`, `p` not dividing `b`; and the exponents `n` with `eta_b = eta_0^n` for every non-fundamental `b` with `|b| <= 3000`, the only prime exponents being 2, 3 and 13 (Rem. 5.5) |

The `E0nn` labels in some script headers are identifiers from the authors' internal
research log and can be ignored.

## Scope

These are the scripts for the results in the paper. The computations for the
exponents `q >= 5` — the genus computations and the appeal to Faltings' theorem
mentioned in Remark 5.5 — belong to a sequel and are not included here.
